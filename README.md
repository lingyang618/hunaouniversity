# 🎓 胡闹大学 Hunaou University

> 一款用 C 语言写成的七日大学生活模拟游戏。
（这是我心血来潮上过第一节c语言课之后瞎做的啊。。全是不合理的剧情和生活 大孩子小孩子中孩子请勿模仿！）
欢迎来到胡闹大学。

你有 7 天时间，每天可以进行 5 次行动。

上课、健身、打游戏、打工、吃饭、睡觉，或者干脆出门乱逛。

你的每一个选择都会改变：

- 😊 心情
- ❤️ 健康
- 📚 学识
- 💴 金钱

七天之后，你会得到属于自己的大学结局。

当然，也有可能根本活不到第七天。

## 👶 出生

游戏开始时可以选择：

### 1. 天龙人

一出生就站在别人毕业后的终点。

### 2. 老鼠人

活着已经消耗了大部分力气。

### 3. 平凡的一块石头

没什么特别，但至少还能滚。

### 4. 管他呢随便吧

把命运交给随机数。

---

## 🕹️ 可以做什么？

每个时间段可以选择：

1. 上课
2. 健身
3. 宅家打游戏
4. 起飞
5. 打工
6. 吃饭
7. 睡觉
8. 出门逛逛

不同的行动会改变不同属性。

有些行动还可能触发特殊事件。

---

## 🎲 随机事件

大学生活当然不可能完全按照计划进行。

你可能会：

- 没挤上电车然后迟到
- 抢到半价便当
- 遇到教授提前下课
- 碰上 Steam 促销
- 在路边发现钱
- 遇到东京突然下雨
- 被自动售货机多送一瓶饮料
- 突然遇到小测验
- 被朋友请客
- 莫名其妙地走运

以及一些什么都没有发生的普通日子。

---

## 🏆 成就

游戏中隐藏着各种成就，例如：

**中国人能飞**  
起飞超过 10 次。

**睡美人**  
睡觉超过 10 次。

**打工皇帝**  
打工超过 15 次。

**学术妲己**  
学识达到 100。

**人形自走蛋白粉**  
健康达到 100。

**Steam大学荣誉毕业生**  
打游戏达到一定次数。

还有其他隐藏成就。

---

## 💀 Game Over

请注意自己的心情和健康。

如果其中某些关键属性归零，你的大学生活可能会提前结束。

## 🖥️ 如何运行

### macOS

需要安装 C 编译器。

在 Terminal 中进入项目目录后：

```bash
clang hunaou.c -o hunaou
./hunaou

Linux

可以使用 GCC：gcc hunaou.c -o hunaou
./hunaou

Windows

目前建议使用 WSL 或其他支持 C 编译的环境运行。

Windows 可直接运行的版本计划在之后提供。
